human eyes see change of brightness geometrically<br>
but monitor brightness changes arithmetically<br>
this script fixes that<br>
left ctrl + up or down arrow to change brightness<br>
left ctrl + left or right arrow to change monitor<br>
left ctrl + left + right to initialize(in case monitor changed)<br>
left ctrl + up + down to terminate<br>
30 calculated stages of brightness<br>
no taskbar icon or anything<br>
